
### CT-001 — Login com campos vazios

**Objetivo:** Verificar se o sistema permite realizar login sem preencher os campos obrigatórios.

**Passos realizados:**
1. Acessar a página de login do SIFIT.
2. Deixar os campos de usuário e senha vazios.
3. Clicar no botão "Entrar".

**Resultado esperado:** O sistema deve impedir o acesso sem as credenciais obrigatórias.

**Resultado obtido:** O sistema impediu o acesso e apresentou a mensagem: "O nome de usuário e senha não correspondem."

**Status:** APROVADO.

**Observação:** A mensagem poderia ser mais específica, informando que os campos de usuário e senha são obrigatórios.
